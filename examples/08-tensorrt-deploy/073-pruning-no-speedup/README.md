# 073 · 权重删了一半，模型为什么没快？

把权重置零，参数一个没少；把网络改小，导出文件确实变小了——但推理速度
还取决于引擎是否重新构建、算子是否被融合、以及瓶颈到底在算力还是带宽。

本篇走完整链路：随机小模型 → 屏蔽部分隐藏单元 → 重建等价的小模型 →
核对两者输出一致 → 分别导出 ONNX，对比参数元素数。

## 观察点

- 参数量减半但推理耗时不变——这正是标题的答案。
- 置零与真删的文件大小差：前两个一样大，只有第三个变小。

## 验证状态

**已实测通过**（CPU，Python 3.14.3，torch 2.14.1），退出码 0：

| 模型 | weight 元素 | 全部参数 |
|---|---|---|
| original | 17,024 | 17,098 |
| masked（权重置零） | 17,024 | 17,098 |
| compact（真实变小） | 8,512 | 8,554 |

三组等价性核对（`zeros` / 随机 7×256 / 放大 10 倍的随机输入）全部通过。
完整输出见 `expected_output.md`。

**注意**：脚本只做等价性与参数量核对，**不测推理耗时**，也不构建 TensorRT 引擎。
"权重减半"到"速度提升"之间还差一整条链路，这正是文章要讲的。
