# 051 · 八张显卡，怎样同时分数据、分层、分矩阵

八张卡同时做数据并行（DP）、流水线并行（PP）、张量并行（TP）。三种并行单看
都懂，凑到一起就有几个数字对不上：八张卡在训几个模型？一条样本走过几张卡？
全局 batch 该乘几？

本篇用一段**纯 CPU 数学模拟**（8 个 rank、`D=P=T=2`）把这三件事钉死：

| 并行 | 切开什么 | 组内通信 | 本篇验证 |
|---|---|---|---|
| TP | 单层矩阵的列 | 组内 AllReduce（不能除以 T） | 梯度与"整模型一次算完"的参考值逐位一致 |
| PP | 模型层段 | 相邻段传激活与梯度 | 每段只拿自己那半参数的梯度 |
| DP | 全局 batch | 组内梯度平均 | 同步后同组副本参数完全相同 |

脚本里每个结论都配一条 `assert`，跑完打印 `PASS` 才算过。

## 前置

048（一层 TP 的切法）、049/050（PP 与显存账本，读概念）。

## 运行

```bash
python parallel_groups_check.py
```

**不需要 GPU，也不需要第三方依赖**（只用标准库 `math.isclose`）。
脚本在模块级执行，无 `main()`；退出码 `0` 且末行 `PASS` 即通过。

## 环境要求

- 无：纯 CPU 数学模拟，零第三方依赖
- 不做多卡通信，也不测性能——它验证的是**拆分口径**，不是带宽

## 观察点

- 三组 rank 划分（TP/PP/DP）必须各自覆盖 0–7 且互不重叠。
- 梯度与「整模型一次算完」的参考值逐位一致；偏差出现在哪一组，就是哪一维的切法错了。
