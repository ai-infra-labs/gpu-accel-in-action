> 篇号 020–026 · 本章 7 篇 · 有独立代码 4 篇 · 全量已实测 1 篇

**本章目标**：把「参数少了」「FLOPs 降了」「文件小了」「跑得快了」这四件事分开算。

**必读**：023 → 026

**最常见的误解**：以为量化就是「把 float 换成 int8 就能加速」。021 会告诉你，反量化之后卷积仍是 fp32，省的是显存与带宽，不是乘加次数。
