# 043 · 模型都放进显存了，为什么反而更慢？

显存够用不代表不争用。两个模型同时驻留、同时跑，会争抢 SM、L2 与显存带宽，
结果可能比串行更慢——"能放进去"和"放进去更快"是两件事。

本篇让两个模型在同一张卡上分别跑串行与双 Stream 并行，逐种模式计时。

042（Stream 与并发）。

## 运行

```bash
python -m pip install -r ../../requirements/python-gpu.txt
python contention_demo.py
```

四种模式：`A`（只跑模型 A）、`B`（只跑模型 B）、`serial`（串行跑两个）、
`parallel`（两个 Stream 并行）。脚本入口会检查 `torch.cuda.is_available()`。

## 环境要求

- 必须：NVIDIA GPU + CUDA 版 PyTorch
- 依赖层：`requirements/python-gpu.txt`
- 显存需求：两个 1024→2048→1024 的模型 + 各 128×1024 输入，量级很小，
  消费级显卡足够

## 观察点

- 两个模型同时跑的耗时落在「单模型×2」的哪一侧：低于它说明有重叠，高于它说明在争用。
- 显存不够时框架会退化到换页或直接 OOM，看耗时曲线会出现台阶而不是线性增长。
