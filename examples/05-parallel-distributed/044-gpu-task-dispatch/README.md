# 044 · 多加一张显卡，任务该交给谁

一张 GPU 排着队，另一张闲着。把请求交给"最空闲"的那张，看上去再合理不过——
可它可能没加载目标模型，也可能数据还没准备好。路由的对象不是"显卡"，
而是**能执行这个模型版本的实例**。

本篇用两个调度策略做对照：

| 策略 | 依据 | 盲点 |
|---|---|---|
| `shortest_queue` | 队列长度 | 队列短不代表前面的工作轻 |
| `earliest_finish` | `max(可用时刻, 数据就绪) + 计算时长` | 需要预估计算时长 |

## 观察点

- 三个场景里两种策略是否挑了同一个实例；第二个（数据准备更慢）是分水岭。
- 「最空闲」不等于「最早完成」：路由对象是能执行该模型版本的实例，不是显卡。
