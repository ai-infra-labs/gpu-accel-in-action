判读方式：

  但**含**最终 D2H。要跟"用户等多久"比，还得把这些再加回去。
- `总浓度比` 与 CPU 参考的量级（`75.4434 / 77.8511 ≈ 0.969`）差得远时，先查边界
  处理：固定零边界会持续把浓度"漏"出去，边界条件写错会让下降幅度大得离谱。
  注意两者网格不同（512 vs 64），这个比值只能当量级参考，不能当等式核对。
- 26 万个线程每个做一次双线性插值，平均每步内核时间应与"512×512 次随机访存"
  的量级相符；若高出十倍，先看是不是每步都同步了。
