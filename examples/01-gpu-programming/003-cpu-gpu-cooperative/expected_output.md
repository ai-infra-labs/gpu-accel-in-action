判读方式：

  `CPU + GPU ≈ 串行`（串行就是两段相加）、`max(CPU, GPU) ≈ 重叠`。

- 相对 Frobenius 误差应在 `1e-7` 量级（1024 项 float32 累加）。

## 3. 这份数据不能说明什么

- **不能直接外推到真实推理**：这里 CPU 做加法、GPU 做乘法，是刻意构造的
  "两件互不依赖的工作"，真实流水线里两段往往有数据依赖。
- **只测了一个规模**：`N=1024` 时 GPU 可能还没进入吞吐主导区，换到 `N=4096`
  结论可能反过来。
