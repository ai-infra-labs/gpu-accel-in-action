# 专栏名称：CUDA 并行实战：从 PyCUDA 手写内核到 AI 推理加速

## 专栏简介

本专栏面向想用 GPU 真正动手写代码、搞懂每一行的工程师。不同于直接讲 cuBLAS/cuDNN 调用的入门教程，本专栏采用**“先写一个能跑但错的 Kernel → 指出问题 → 拆解原理 → 给出修正版 → 验证正确性与性能”**的踩坑式教学路线，用 PyCUDA 从零手写 CUDA 内核，一步步讲透 GPU 并行的本质。

全专栏共 28 篇，按依赖递进分为 6 个部分：

- **Part 1：PyCUDA 入门与性能心智（1-4）**：线程映射、前向/反向、CPU-GPU 协同、异步传输与双缓冲
- **Part 2：线程映射与图像算子（5-9）**：坐标映射、2D/3D 卷积、Kernel Fusion 实战
- **Part 3：同步·共享内存·矩阵乘（10-13）**：归约、扫描、分块矩阵乘、cuBLAS 语义与内存流
- **Part 4：变换域与经典算法（14-16）**：双调排序、朴素 DFT、FFT 卷积
- **Part 5：科学计算（17-19）**：N-Body、热传导、流体网格演示并行通用思路
- **Part 6：模型压缩与推理加速（20-28）**：压缩全景、量化、知识蒸馏、剪枝、CSR 稀疏、端到端推理到 TensorRT 加速

## 学习收获

- **透彻理解 GPU 并行**：从线程、Block、Grid 到共享内存、同步边界，学会用数学和代码验证自己的认知
- **学会踩坑式调试**：掌握计时边界（主机时钟 vs CUDA Event）、数据竞争、越界、异步提交≠重叠等最常踩的坑
- **动手实战 PyCUDA**：全程手写可直接跑通的 CUDA 内核，重点讲清“为什么这么写”而非“怎么调用”
- **打通 AI 推理加速脉络**：从内核优化到模型压缩（量化、蒸馏、剪枝）再到 TensorRT，建立一套“算子→模型→服务”的工程视角
- **培养工程验证意识**：用 NumPy 对比正确性、预热+多次测量取中位数/P95、区分内核时间与端到端耗时

## 适用人群

- 想深入 GPU 底层原理却找不到能跑的动手教程的工程师
- 学过 CUDA 基础但对 `__global__`、共享内存、`__syncthreads` 用法还模模糊糊的开发者
- AI Infra / 算子优化方向入门，想先用 PyCUDA 搭建“手写内核”的直觉再转 CUDA C
- 对“模型明明上了 GPU 却还是慢”感兴趣，想搞清楚瓶颈到底在哪一环

> 专栏不止教会你写一个 Kernel，更要教会你：**看见一个并行问题时，如何把它拆解、映射到 GPU、验证、优化。**
