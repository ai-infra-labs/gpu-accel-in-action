# 023 · 参数缩到 1/106，计算量却只少了 27%

小模型"小"在哪，不能只看参数量。把分类头从全连接换成全局平均池化（GAP），
参数从 212 万降到 2 万，但卷积主体的计算量一个没少——所以推理不会跟着快 106 倍。

本篇做结构检查：分别构建 FC / GAP 两种分类头，统计总参数、分类头参数、
参数字节数与前向输出形状。

## 观察点

- 参数量比值应是约 106 倍，而计算量只降 27%——两个数一起看才有意义。
- GAP 把 H×W 平均掉，参数量减少来自分类头的输入维度，不是卷积层。

## 验证状态

**已实测通过**（CPU，Python 3.14.3，torch 2.14.1），退出码 0：

| 结构 | 总参数 | 分类头参数 | 参数字节 | 输出形状 |
|---|---|---|---|---|
| FC-CE | 2,122,186 | 2,102,794 | 8,488,744 | (2, 10) |
| GAP-CE | 20,042 | 650 | 80,168 | (2, 10) |

参数量比值 105.89。完整输出见 `expected_output.md`。

注意：脚本只做结构检查，**不测推理耗时**。参数少不等于算得少，
这正是文章要纠正的认知。
