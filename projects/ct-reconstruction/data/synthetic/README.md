# data/synthetic

**这里不存任何真实医学影像。**

`fdk_demo` 的数据全部在内存里解析生成（见 `src/utils.cu`）：

- **phantom**：若干椭圆叠加的灰度图，模拟一个横断面；
- **sinogram**：同一组椭圆在平行束下的解析线积分，有闭式解，无离散化噪声。

之所以不在磁盘上放 `.npy` / `.bin`：

1. 合成数据 1 KB 代码就能生成，落盘反而引入「文件找不到」这类与教学无关的失败；
2. 每次运行结果完全一致，不同实现之间可以逐值对比；
3. 真实 DICOM / NIfTI 涉及隐私与体积，不属于本示例的范围。

要换成真实数据，只改 `src/utils.cu` 的两个生成函数，其余模块不用动——
这正是它们被单独放在一层的原因。
